## 与《学透》的关系

HLT原为《学透》第八章。本书是对同一工具的AI时代场景化展开，侧重"决策焦虑"而非"学习质量"。《学透》保留HLT作为学习操作系统中的选择组件，本书独立为"不知道学什么"这一特定恐惧的完整解法。
