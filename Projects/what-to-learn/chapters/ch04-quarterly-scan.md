# 第四章：季度扫描——把选择变成周期

HLT不是一次性判决。你今天的评分，三个月后可能完全失效——因为你的位置变了，环境变了，AI本身也变了。

所以HLT需要一个载体：**一个可重复的决策周期。**

我建议按季度走。大多数人没有精力每月做一次完整的扫描，但三个月一次是可维持的。不靠热情维持——靠日历上的固定时间。

## 4.1 季度扫描流程

每季度的最后一周，留出30分钟。不需要更长了——30分钟完成以下五步。

**第一步：列出10个候选方向（5分钟）**

写下你当前正在考虑的学习方向。不要只写已经决定学的东西——把那些反复出现在你脑子里、持续消耗注意力的候选项也写出来。

规则：方向要写具体，不要写"数学"——写"线性代数中的向量空间和矩阵分解"。不要写"AI"——写"大模型应用开发的基础概念和工具"。具体才能打分。

例子：

```text
1. 物理中的受力分析和电路分析方法
2. 数据分析的基本流程和常用图表
3. 系统编程中的资源管理和内存安全概念
4. 英语中的动词时态变化规律
5. 提示词工程和模型沟通技巧
6. 大单元教学设计的理论和实践
7. 团队决策工具和冲突处理方法
8. 深度学习中的基础数学
9. 写作中的结构和逻辑组织
10. 某个近期需要使用的特定工具
```

**第二步：HLT评分（10分钟）**

对每个方向打分H、L、T，每个分数写一句理由。

不需要长篇大论——一句话说明为什么这个分数。

```text
方向：团队决策工具和冲突处理方法
H：7（具体工具会变，但协作决策的原理长期有效）
L：6（能提升当前团队协作质量，但不是核心技能的瓶颈）
T：7（能迁移到任何需要协作的场景）
HLT：7×6×7=294 → 高价值
```

**第三步：淘汰（5分钟）**

低于75的，划掉。它们不值得进入你的深度学习预算。

```text
75以下：不学。（告诉自己不学比学好，真心这样认为）
```

75-149：快速了解。登记到下季度轻量学习列表，用一篇文章或一个案例快速了解。

150-299：高价值。如果它与当前阶段的关键路径相关，值得在每周学习中分配时间。不一定要走精通五层的全部步骤——学到"可用"程度即可。

300以上：核心杠杆。走精通五层流水线（选方向→找基线→做预测→跑实验→找边界→封装）。

这个阈值不是死的——如果你觉得250但确实是你当前最需要的，可以调。但只能因为"我对这个知识的信心高于标准"而调，不能因为"我觉得不学不行"而调。

**第四步：锁定1-2个深度目标（5分钟）**

这是最硬的一步。季度目标不能太多。

一个深度目标真正走完精通五层的Level 3（参数实验）和Level 4（边界实验），就会占用稳定的注意力。如果你选了三个以上深度目标，意味着你还没有真正选择——你只是在收集备选。

选好了，写下来：

```text
本季度深度目标：
1. X方向（HLT=XXX）——为什么值得投入
2. Y方向（HLT=XXX）——跟X交替推进

轻量了解：
- Z方向（HLT=92）——读一篇文章了解概念
- W方向（HLT=75）——遇到相关问题时再查

本季度放弃：
- A方向（HLT=56）——对当前阶段杠杆太低
- B方向（HLT=42）——热度驱动的假机会
```

**第五步：对上季度做5分钟复盘（5分钟）**

上一季度锁定的目标，现在回头问三个问题：

1. 当时的HLT评分成立了吗？哪些方向的分需要调？
2. 哪些学习投入产生了真实的能力迁移？
3. 哪些只是满足了新鲜感，但没有产出可运行的判断？

把答案写在季度计划旁边。它是下一个季度打分的基础。

## 4.2 月度复核：检测HLT变化

季度扫描是深度决策。月度的复核是轻量校准——回答一个更简单的问题：**这个月有什么变化让我的HLT需要调整？**

可能是外部变化：你突然接了一个新项目，需要某个之前没考虑的方向。
可能是内部变化：你发现某个方向学起来比预期更困难，或者更容易。
可能是AI变化：一个工具的发布让某个方向上层的价值大幅上升或下降。

月度复核只需要5分钟。问自己三个问题：

1. 上个月瞄准的深度方向和当前的大致手头事务之间，有没有冲突？
2. 有没有应该从这个月列表移除的方向——因为HLT变了，或者因为不再感兴趣？
3. 有没有突然出现在你视野里、值得列入季度列表但不值得马上投入的方向？

这三个问题不需要写详细的打分。它的作用不是改变你已经做出的季度决策——是在下一次季度到来之前，保持你的选择系统和生活状态之间的一致性。

## 4.3 放弃清单：不学什么比学什么更重要

如果你做了一轮完整的季度扫描，你会发现一个事实：**多数你想学的东西，HLT评分其实不高。**

你一直放不下它们，不是因为它们真的重要——是因为你从没认真算过账。

一旦你把分数写下来、把理由列出来，它们就从一个"可能错过重要知识"的焦虑，变成一个"目前不值得投入"的决策。

放弃清单让你从一个什么都没选的状态，进入一个有意识放弃的状态。这两种状态的差别巨大——前一种让你焦虑，后一种让你清楚。

写放弃清单的规则：

1. 每个放弃的方向也要写理由。不是说"这不重要"，而是说"对我当前阶段不重要，因为……"
2. 放弃不等于永久放弃。写下它的名字，也写下"什么条件达成后可以重新考虑"。
3. 放弃清单贴在季度计划旁边。不是藏在角落——是让你看见的。

你这样告诉自己：我不是放弃了这些知识——我是给自己的深度学习留出了空间。

## 4.4 产出审查：两周无产出就暂停

这是所有长期学习者的最大陷阱。

你选定了一个高HLT的方向，开始投入。但一个月过去了，两个月过去了——你在读，在看，在学——但没有任何可交付的产出。

没有预测验证，没有封装句，没有能独立输出的判断成果。

问题可能不是你不努力，而是这个方向的"学"和"做"之间的接口还没找到。你一直在输入，没有进入输出的循环。

定一个规则：**一个学习投入超过两周但没有任何产出——不一定是大产出，但必须是可运行的判断——暂停它。** 不是放弃——是暂停。两周后如果你发现自己根本没有想回去继续，那停的原因不是"暂时没空"，而是这个方向对你的真实吸引力远不如你想象的大。

产出不一定是代码、文章、产品。它可以是一个参数实验的记录、一段自己写的总结、一个能告诉别人的判断（"改了这个参数后会怎么样"）。但它**不能**是笔记、划线、收藏——那些是动作，不是产出。

两周是一个合理的阈值。如果你在这个方向上投入了两周，连一次预测都没做过——那你在学什么？
