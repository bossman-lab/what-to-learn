# 规律如何被计算机高效抽象

### —— 技术附篇二 · 从「未知」到「被高效利用」的完整流程

> 附篇一《Jev 技术拆解》讲的是"判断"的抽象。
> 本篇讲的是"规律"的抽象：**一个藏在世界里的规律，怎样一步步变成计算机能高效利用的东西？**

---

## 一、总览：八个阶段，八次"表示的变换"

**核心视角**：整个流程的本质不是"信息搬运"，而是**表示的连续变换**——每一步都在把规律换成一个**更可操作**的形式。

```
⓿ 工具化   原理 → 装置
① 观测     世界 → 数据
② 发现     数据 → 规律
③ 形式化   规律 → 符号
④ 算法化   符号 → 过程
⑤ 高效化   过程 → 快过程
⑥ 学习     数据 → 表示      ← 端到端，跳过 ②③④
⑦ 泛化     表示 → 能力
```

**注意 ⓿ 的位置**——它**通常先于 ① 发生**。这一点后面单独展开（第三节）。

**先给一个对应关系**——这八步正好铺在前面的三道鸿沟上：

| 鸿沟 | 对应阶段 |
|------|---------|
| **认识鸿沟** | ⓿ 工具化 + ① 观测 + ② 发现 + ③ 形式化 |
| **计算鸿沟** | ④ 算法化 |
| **实现鸿沟** | ⑤ 高效化 + ⑥ 学习 + ⑦ 泛化 |

---

## 二、逐阶段详解

### ⓿ 工具化：原理 → 装置

**机制**：把规律**先做成能用的东西**——不管理论上懂不懂。

**关键**：**这一步是"数据"和"动机"的来源。**

· 蒸汽机造出来了（1712），才有热力学的数据（供卡诺 1824 分析）
· 电报通了（1830s），才有电磁学的工程验证场
· 望远镜架起来了，才看到木星的卫星

| 维度 | 说明 |
|------|------|
| **产出** | 可用装置 + 数据 + 验证场 |
| **常态** | **工程领先于科学** |

**这是最容易在"抽象流程"里被忽略的一步——但它往往是最早发生的。**

---

### ① 观测：世界 → 数据

**机制**：仪器把世界的状态转成可记录的信号。

**关键洞察**：**可观测性是被"仪器"决定的，不是被"世界"决定的。**

没有望远镜 → 看不到木星卫星；没有加速器 → 看不到夸克；没有空间望远镜 → 测不到系外行星大气。

**这就是"你只能问你已能问的问题"在流程上的体现。**

| 维度 | 说明 |
|------|------|
| **产出** | 数据（raw measurements）|
| **瓶颈** | 精度、噪声、尺度（量子 ↔ 宇宙）|
| **常见错误** | 以为"有了数据就有了规律"|

**注意**：**数据 ≠ 信息 ≠ 规律。** 这一步只生产"原始记录"。

---

### ② 发现：数据 → 规律

**机制**：**压缩**——在假设空间里，找**最短的、能预测数据的描述**。

**这是全流程最关键的一步，而它的数学形式就是压缩**：

· **Kolmogorov 复杂度**：规律的"长度" = 输出数据的最短程序长度
· **MDL 原理**：最好的模型 = 描述 + 误差之和最小
· **Solomonoff 归纳**：最优预测 = 对所有一致假设加权

> **发现规律 = 压缩数据。**

**这一步由两个子过程组成，缺一不可**：

| 子过程 | 做什么 | 靠什么 |
|--------|--------|--------|
| **探索** | 提出候选假设 | 想象力 / 搜索 |
| **验证** | 淘汰错的假设 | **实验（问世界）** |

**瓶颈**：**搜索不可约**——假设空间天文级，你无法"推导出"哪个对，只能试。

**关键细节**：**数据里有规律 ≠ 有人找到了它。** 第谷的数据在开普勒之前就在那里。

| 维度 | 说明 |
|------|------|
| **产出** | 规律（显式、可陈述）|
| **例子** | 开普勒三定律 → 牛顿万有引力（进一步压缩）|
| **瓶颈** | 假设空间搜索不可约 |

---

### ③ 形式化：规律 → 符号

**机制**：用**精确的符号语言**（数学 / 逻辑）重写规律。

**为什么这一步是"加速器"**：

> **符号是可操作的**——可以组合、变换、推导、证明、代入。

| 阶段 | 形式 | 能做什么 |
|------|------|---------|
| 未形式化 | "物体下落越来越快" | 只能描述 |
| **已形式化** | **s = ½gt²** | **可微 · 可积分 · 可代入 · 可组合** |

**关键**：形式化把"**描述**"变成"**可操作的表示**"。

**这一步没有鸿沟**——它是纯增益。一旦形式化，就获得了**推导能力**、**组合能力**、**证明能力**。

**例子**：麦克斯韦把电磁现象写成四个方程 → 直接"推导"出电磁波存在 → 几十年后赫兹证实。

---

### ④ 算法化：符号 → 过程

**机制**：把形式表达变成**可执行的步骤**：

· **闭式解**（能求出来时）→ 直接算，最快
· **离散化 / 数值方法**（求不出时）→ 一步步逼近
· **迭代 / 模拟** → 让系统跑

**核心障碍：计算不可约。**

| 情况 | 例子 | 后果 |
|------|------|------|
| **有解析解** | 二体问题、简谐振动 | ✅ 直接算，快 |
| **无解析解** | **三体问题**、湍流、蛋白质折叠 | ❌ **必须跑**，无法加速 |

> **有规律 ≠ 有公式。当规律不可约时，"预测"的唯一办法是"模拟"。**

**这是全流程最硬的一堵墙。**

---

### ⑤ 高效化：过程 → 快过程

**机制**：**发现结构**，让同样的计算变快。

| 手段 | 原理 |
|------|------|
| **算法复杂度** | O(n²) → O(n log n) |
| **并行** | GPU / 分布式 |
| **硬件匹配** | 缓存、SIMD、专用芯片 |
| **近似** | 牺牲精度换速度 |

**这才是"被计算机高效抽象"的真正含义**：

> **不是"算得更快"，而是"用更少的运算达到同样的结果"。**

**收益的真正来源是【结构的发现】**：

| 结构 | 例子 | 收益 |
|------|------|------|
| **周期性** | **FFT** | O(n²) → O(n log n) |
| **稀疏性** | 稀疏矩阵 | 内存 / 时间大降 |
| **低秩** | 矩阵分解 | 参数量骤减 |
| **对称性** | 群论简化 | 指数级约简 |

**关键洞察**：

> **换一个表示，速度可以差几个数量级。**

· 朴素 DFT：n = 10⁶ 时需要 ~10¹² 次运算
· FFT：同样问题 ~2×10⁷ 次运算
· **收益 5 万倍——不靠任何新硬件**

---

### ⑥ 学习：数据 → 表示（端到端）

**这是当代的转折点：它把 ②③④⑤ 合并成了一步。**

**机制**：参数化 + 梯度下降。

```
数据 → [参数化模型] → 梯度下降 → 权重（= 隐式的规律）
```

**关键洞察：神经网络是"自动的压缩器"。**

· 训练 = 找一组权重，使函数拟合数据
· **权重 = 隐式的规律**
· **泛化 = 压缩成功的证据**（能压缩，说明抓住了结构）

**革命性在哪**：

| 传统路径 | 学习路径 |
|---------|---------|
| 人类形式化（③）| **不需要** |
| 人类算法化（④）| **不需要** |
| 能处理"讲不清"的规律 | ✅ 图像、语言、语音 |

**但代价很大**：

| 代价 | 说明 |
|------|------|
| **隐式** | 规律在权重里，**写不出来** |
| **不可解释** | 无法陈述"它学到了什么" |
| **不可验证** | 无法证明它抓的是"真规律"而非"伪相关" |
| **外推脆弱** | 只在训练分布附近可靠 |

---

### ⑦ 泛化：表示 → 能力

**机制**：**压缩 → 抓住共同结构 → 迁移到新输入**。

> **泛化是压缩的必然结果——能压缩，说明抓住了共性。**

**但边界很硬**：

| 泛化类型 | 可靠性 |
|---------|--------|
| **同分布内** | ✅ 可靠 |
| **轻微偏移** | ⚠️ 一般 |
| **分布外（OOD）** | ❌ **脆弱** |

**这就是为什么"隐式抽象"永远需要人类守着**——它不知道自己什么时候越界了。

---

## 三、关键观察一：**工具化先行**

**这是本附篇最重要的一条观察：**

> **一个规律在被计算机抽象和利用之前，大概率已经完成了"工业或物理层面的工具化"。**

### 历史证据

| 领域 | 工具化（物理/工业）| 理论形式化 | 计算抽象 |
|------|------------------|-----------|---------|
| **力学** | 远古·杠杆齿轮 | 1687·牛顿 | 1950s·数值模拟 |
| **热学** | **1712·蒸汽机** | 1824·卡诺 | 1960s·热仿真 |
| **电磁** | 1830s·电报 | 1865·麦克斯韦 | 1970s·电磁仿真 |
| **流体** | 古代·泵/风车 | 1738·伯努利 | 1960s·CFD |
| **空气动力** | **1903·首次飞行** | 1920s·升力理论 | 1960s·CFD |
| **遗传** | 数千年·育种 | 1865·孟德尔 | 1990s·基因组计算 |

**规律极其一致：工具化 → 理论 → 计算。**

**注意几个"晚了多少年"**：
· 蒸汽机 1712 → 热力学 1824：**晚了 112 年**
· 首次飞行 1903 → 升力理论 1920s：**晚了近 20 年**
· 育种数千年 → 孟德尔 1865

> **人类经常先做出"能用但不懂"的东西。**

### 为什么大概率是工具化先行？

**三个结构性原因**：

| 原因 | 说明 |
|------|------|
| **① 经济回报的次序** | 工具化直接产出价值（蒸汽机能抽水赚钱）；计算抽象只在"规模值得优化"时才有回报 |
| **② 工具是数据的生成器** | 计算抽象需要数据，而工具化正是数据的来源。**没有蒸汽机，就没有热力学数据** |
| **③ 工具是验证场** | 抽象需要"问世界"，而物理工具就是"世界"的接口。**你不能纯靠想验证 CFD——你需要风洞** |

**再加上自举回路**：

```
工具化 → 数据 → 抽象 → 更好的工具 → 更多数据 → ...
```

### 但有个例外规律：什么时候"理论"反而先行？

**并非总是工具先行。** 反例：

| 领域 | 理论 | 工具化 | 间隔 |
|------|------|--------|------|
| 相对论 / 核能 | 1905 | 1945·核能装置 | 40 年 |
| 激光 | 1917·受激辐射 | 1960·激光器 | 43 年 |
| 通用计算 | 1936·图灵机 | 1947·晶体管 | 11 年 |

**决定次序的规则**：

> **哪条路更便宜，就走哪条。**

· **能"做"比能"懂"容易** → 工具先行（大多数领域）
· **能"懂"比能"做"容易**（数学结构干净、或工具的技术前提尚不具备）→ 理论先行

**这就是为什么**：
· 流体力学**先有风车后有 CFD**（算不动，但能吹风洞）
· 相对论**先有方程后有核能**（数学干净，但造装置要等 40 年）

### 这条观察的深层含义

**它戳破了一个流行的错觉：以为"科学指导工程"。**

**实际上，工程经常领先于科学：**

> **人类先做出能用的东西，再花几十年搞懂为什么能用。**

**这也解释了为什么"理论"常常显得滞后**——**因为理论要等工具把数据造出来。**

## 四、关键观察二：两条路径（显式 vs 隐式）

```
路径 A（显式）：⓿ → ① → ② → ③ → ④ → ⑤
路径 B（隐式）：⓿ → ① → ⑥ → ⑦
```

**路径 B 直接跳过了 ②③④。**

| | **显式**（传统科学 / 算法）| **隐式**（学习）|
|---|---|---|
| 规律在哪 | 公式、算法里 | **权重里** |
| 能否陈述 | ✅ 能 | ❌ 不能 |
| 可解释 | ✅ 是 | ❌ 否 |
| 数据需求 | 少（但要洞察）| **多** |
| 覆盖范围 | 精确但窄 | 广但模糊 |
| 外推 | 可靠 | **脆弱** |
| 代表 | F = ma | GPT |

**两者不是取代关系，是互补关系。**

**理想形态可能是**：

> **用隐式表示做"发现"，用显式表示做"验证"。**

（这正是 Jev 的思路：输出强类型的、可验证的判断。）

---

## 五、关键观察三：**"高效"不来自算力**

| | 算力路线 | 结构路线 |
|---|---------|---------|
| 收益 | 线性 | **数量级** |
| 上限 | 有（物理极限）| **持续（结构无穷）** |
| 成本 | 持续投入 | **一次发现，永久收益** |
| 本质 | 更多运算 | **更少运算** |

**三个层次的"结构发现"**：

| 层次 | 内容 | 例子 |
|------|------|------|
| **数学结构** | 利用内在性质 | FFT 用周期性 |
| **算法结构** | 利用问题形态 | 分治、动态规划 |
| **表示结构** | 换一个坐标系 | 稀疏表示、嵌入、坐标变换 |

**而"结构发现"本身是可约的**——一旦发现，收益永久保留。

**这就是为什么要"高效抽象"：不是让机器更快，而是让问题更小。**

---

## 六、闭环：机器反过来加速发现

**现在，⑦ 又回到了 ⓿/①**：

```
⑥ 学习 → ⑦ 泛化 → 【作为新工具】→ ⓿ 工具化 → ① 观测 → ② 发现 → ...
```

**计算机不再只"执行"规律，还开始"发现"规律**：

| 领域 | 例子 |
|------|------|
| 生物学 | AlphaFold 发现蛋白质折叠结构 |
| 数学 | AI 辅助猜想与证明 |
| 材料 | 新材料的结构搜索 |
| 药物 | 分子筛选 |

**这意味着问题空间在扩张**：**每一次成功的抽象，都会打开新的可观测窗口。**

**而这也解释了为什么 AI 比传统领域快**：

> **在软件里，"工具化"这一步被压缩掉了——工具本身就是软件。**
> **所以 AI 跳过了"物理工具化"的年级延迟，直接跑在"周级"的时钟上。**

（这正是前面说的"三个时钟"的根源。）

---

## 七、边界：哪里永远卡住

| 卡点 | 为什么 |
|------|--------|
| **计算不可约** | 必须跑，无法加速（三体、湍流）|
| **观测极限** | 某些东西原理上不可观测 |
| **隐式的脆弱** | OOD 失效，且系统不知道自己失效了 |
| **验证的必要性** | 隐式表示无法自我证明，必须外部验证 |

> **能加速的，是"有结构可发现"的部分。**
> **不能加速的，是"计算不可约"的部分——那里只能用时间换答案。**

---

## 八、结论

> **完整流程是八次表示的变换：**
> **装置 → 数据 → 规律 → 符号 → 过程 → 快过程 → 表示 → 能力**
>
> **其中四次收益最大**：
> · **⓿ 工具化**（把原理变成可用的东西，同时产出数据）
> · **② 发现**（把数据压成规律）
> · **⑤ 高效化**（把过程换成更省运算的表示）
> · **⑥ 学习**（把 ②③④⑤ 合并成一步）
>
> **三个关键观察**：
> 1. **工具化先行** —— 规律在被"算出来"之前，早已被"用起来"（工程领先于科学）
> 2. **两条路径** —— 显式（可陈述）与隐式（可拟合）互补
> 3. **高效来自结构** —— 换一个表示，速度差几个数量级
>
> **最后的边界是硬性的**：
> **能加速的地方，是因为有结构；**
> **不能加速的地方，是因为计算不可约——那里，宇宙不允许抄近路。**
