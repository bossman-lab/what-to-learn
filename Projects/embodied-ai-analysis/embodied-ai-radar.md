## 二、关键标的档案

### 2.1 信度启源（新条目 ⭐ 2026-08-10 加入）

| 项目 | 内容 |
|------|------|
| 全称 | 杭州信度启源人工智能科技有限公司 |
| 背景 | **清华大学数学系刘宝碇教授**团队创立，2026 年成立，正在新一轮融资 |
| 技术 | "不确定微分几何"白盒世界模型（信度世界模型） |
| 理论基础 | 不确定理论（Uncertainty Theory）——刘宝碇创立，区别于概率论的数学分支（次可加信度测度） |
| 发布 | 2026-08-06 机器之心报道 |
| 架构 | "七窍"框架：听觉/触觉/视觉感知 + 校验（前庭类比，毫秒级可信边界校验）+ 预测（顶叶）+ 决策（信度最大化，不做概率采样）+ 控制（小脑） |
| 声称 | 无需海量数据预训练；抓取/递送"部署即用"；产线定制周期从数月压缩至"部署即用"；抗扰动、不针对新场景重训 |
| 演示 | 未标定房间 + 无预训练 + 1 个月部署，人形机器人完成语音→抓取→递送全流程 |
| 已验证 | 公司背景/融资/技术路线（机器之心+新浪+腾讯交叉验证） |
| **未验证** | 泛化边界（抓水杯→精密装配？单机→多机？开放环境？）；产线长期运行数据；感知层仍是黑盒 |

**点评结论（2026-08-10）**：
- 理论可行性 ⭐⭐⭐⭐（数学体系真实，哲学批评成立）
- 工程可行性 ⭐⭐（只有 demo）
- 产业可行性 ⭐⭐⭐（痛点真实，路线太新）
- **"不确定微分几何"是品牌化组合**：微分几何（真实）+ 不确定理论（真实）的组合名，真正的创新点=用次可加信度集替代概率分布做安全边界计算
- **与 AI-QC 的关系**：它的校验模块 = AI-QC L3 层（物理约束验证）在控制领域的化身——**外部验证了"物理约束验证"需求真实、有资本买单**
- **跟踪重点**：① 新一轮融资是否落地（金额/投资方）② 是否发布产线长期运行数据 ③ 跨平台适配（工业机器人/人形机器人）

## 五、Coding Agent 生态观察（2026-08-10 新增）

> **趋势信号：harness 自我改进 / 极简化成为 coding agent 主战场**

| 项目 | 作者/背景 | 核心 | 状态 | 评价 |
|------|----------|------|------|------|
| **Pi** | Mario Zechner（libGDX 作者） | 4 工具极简 harness，<1000 tokens，零隐藏注入；OpenClaw 核心框架 | 24k 星，Terminal Bench 前五 | ⭐⭐⭐⭐ 极简哲学验证"少即是多"；与 Hermes 互补 |
| **Prime Agent** | Prime Intellect | RLM（递归语言模型）+ Continual Harness（/refine 自我改进）；ARC-AGI-3 声称 95.5% | 8/6 发布，10.8k 星 | ⭐⭐⭐ 理念领先，成绩有水分（Opus 5 编排 + 自报基准 + 原作者不认领） |

**关键洞察**：
- Pi 是"静态极简"（harness 固定透明），Prime Agent 是"动态自改进"（harness 自我进化）——同一趋势的两端
- 两者共同指向：**coding agent 的竞争从"堆功能"转向"harness 设计"**
- 对 Hermes 的启示：技能沉淀（skills）正从手动走向自动——Pi 的 extensions 和 Prime 的 /refine 都是可借鉴方向

**详细对比**：见 `pi-vs-hermes.md`

## 六、AI-QC 关联信号（重要）

> **物理约束验证 = 安全关键场景刚需**（核能/医疗/机器人/自动驾驶）
> 证据链：张宏亮（核材料预测需物理合规溯源）→ 信度启源（可信边界校验模块）→ 中科院核能大模型（AI 输出附带物理合规溯源链路）

→ **AI-QC 定位升级建议**：从"AI 输出质量保障"→"安全关键场景的物理一致性验证"（有物理约束的 QC，门槛高、竞争少）
